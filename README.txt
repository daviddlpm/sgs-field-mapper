SGS Field Mapper PWA

Instalación:
1. No abra index.html con doble clic ni file://.
2. Sirva esta carpeta por HTTPS o localhost.
3. Abra index.html en Chrome o Edge.
4. Use el menú del navegador: Instalar aplicación / Instalar SGS Field Mapper.
5. Para offline, abra la app con conexión, descargue las teselas de la zona desde el control Offline y espere a que termine.

El service worker almacena la interfaz y recursos visitados. Las teselas dependen de la descarga previa y de las políticas de los proveedores cartográficos.
